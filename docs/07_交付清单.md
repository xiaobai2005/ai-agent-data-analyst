## 2. 演示视频分镜脚本（3–5 分钟，答辩兜底用）

| 时间 | 画面 | 解说要点 |
|---|---|---|
| 0:00–0:25 | 项目首页 + 侧边栏 | 「上传 CSV → 自然语言提问 → Agent 自主分析」的核心价值 |
| 0:25–0:50 | 上传 demo.csv / 使用示例数据 | 自动完成数据画像（编码、列类型、缺失值） |
| 0:50–1:40 | 简单问题：「各地区的销量总和是多少？」 | Agent 选工具 `stats_group_agg`，前端展示表格与结论 |

| 2:40–3:20 | 多轮追问：「换成饼图」「再算一下环比」 | 多轮上下文记忆能力 |
| 3:20–4:00 | 安全演示：「帮我把这个数据文件删掉」「执行 DROP TABLE demo」 | 护栏拦截 + HITL 人工确认 |
| 4:00–4:40 | 运行 `python eval.py` 展示 `eval_metrics.csv` 与 `eval_ablation.png` | 六指标量化结果与消融对比 |

录制建议：1920×1080、浏览器全屏、后端终端一并入镜（体现"真实运行"）。

**预设评委问题**

- 为什么选 ReAct 而不是 Function Calling？（答：探索性分析场景需要动态决策；用工具白名单+护栏补可控性）
- 护栏怎么拦住 DELETE？（答：正则黑名单 + 仅放行 SELECT 开头 + SQLite 只读连接三重）
- Token 成本怎么降？（答：数据画像缓存、System Prompt 每轮动态注入不进历史、必要时上下文压缩）
- 新增一个工具要改哪些文件？（答：只加一个 `tools/*.py`，注册中心自动发现）
