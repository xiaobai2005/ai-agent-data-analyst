# 04 · 部署说明

本文覆盖四种部署方式：**本地 / 服务器 / Docker / 云平台**。任选其一即可。

## 0. 部署前检查

```bash
python -V                       # ≥ 3.10
python -m tools.registry        # 应打印 11 个工具
python tests/test_tools.py      # 应全部 PASS（不消耗 Token）
```

配置文件：把 `.env.example` 复制为 `.env` 并填入密钥（**`.env` 已在 `.gitignore` 中，切勿上传**）。

```ini
OPENAI_API_KEY=sk-你的密钥
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
MODEL=qwen-plus
```

| 变量 | 必填 | 说明 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | 大模型密钥 |
| `OPENAI_BASE_URL` | ✅ | 兼容 OpenAI 的接口地址 |
| `MODEL` | ✅ | 模型名，如 `qwen-plus` / `deepseek-chat` / `gpt-4o-mini` |
| `MODEL_PROVIDER` | ⬜ | 默认 `openai`（兼容接口均可用） |
| `API_URL` | ⬜ | **前端**访问后端的地址，云端部署必填 |

## 1. 本地部署（演示 / 开发）

### Windows

```bat
scripts\start_backend.bat     :: 自动建 .venv、装依赖、起后端 :8000
scripts\start_frontend.bat    :: 起前端 :8501
scripts\start_all.bat         :: 一键同时启动前后端（两个窗口）
```

### macOS / Linux

```bash
bash scripts/start.sh backend
bash scripts/start.sh frontend
bash scripts/start.sh all      # 后台运行，日志在 logs/
```

### 手动方式（通用）

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env && vim .env

uvicorn api:app --reload --port 8000        # 终端 1
streamlit run app.py                        # 终端 2
```

访问：前端 http://localhost:8501 · 接口文档 http://localhost:8000/docs

## 2. 服务器部署（Linux 生产）

```bash
# 1) 安装依赖
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
apt-get install -y fonts-wqy-zenhei        # 中文字体，否则图表中文变方块

# 2) 后台启动（会话状态在内存，请保持单 worker 或改用 Redis）
nohup uvicorn api:app --host 0.0.0.0 --port 8000 > logs/backend.log 2>&1 &
API_URL=http://<服务器IP>:8000 nohup streamlit run app.py \
  --server.port 8501 --server.address 0.0.0.0 > logs/frontend.log 2>&1 &
```

**用 systemd 托管**（推荐，示例 `/etc/systemd/system/agent-api.service`）：

```ini
[Unit]
Description=Agent API
After=network.target

[Service]
WorkingDirectory=/opt/ai-agent-data-analyst
Environment="PATH=/opt/ai-agent-data-analyst/.venv/bin"
EnvironmentFile=/opt/ai-agent-data-analyst/.env
ExecStart=/opt/ai-agent-data-analyst/.venv/bin/uvicorn api:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now agent-api
```

**Nginx 反向代理 + HTTPS**（片段）：

```nginx
server {
    listen 80;
    server_name your.domain.com;
    location / { proxy_pass http://127.0.0.1:8501; proxy_set_header Host $host; }
    location /api/ { proxy_pass http://127.0.0.1:8000/; }
    # WebSocket / SSE 需要关闭缓冲
    location /chat/stream { proxy_pass http://127.0.0.1:8000/chat/stream;
        proxy_buffering off; proxy_cache off; proxy_read_timeout 300s; }
}
```

> ⚠️ SSE 必须关闭 Nginx 缓冲（`proxy_buffering off`），否则前端收不到流式事件。

## 3. Docker 部署

```bash
cp .env.example .env            # 填入密钥
docker compose up -d --build    # 后端 :8000 + 前端 :8501
docker compose logs -f backend
docker compose down
```

单容器快速体验：

```bash
docker build -t agent-platform:1.0 .
docker run -p 8000:8000 -p 8501:8501 --env-file .env agent-platform:1.0
```

## 4. 云平台部署（Cloud Studio / 云服务器 / 容器平台）

1. **上传代码**：上传整个项目目录（排除 `.env`、`.venv`、`__pycache__`、`__pycache__`、运行产物）
2. **安装依赖**：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
3. **配置环境变量**：在平台面板设置 `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `MODEL` / `API_URL`
4. **启动命令**：
   - 后端：`uvicorn api:app --host 0.0.0.0 --port 8000`
   - 前端：`streamlit run app.py --server.port 8501 --server.address 0.0.0.0`
5. **开放端口**：8000（后端）、8501（前端）
6. **关键**：前端的 `API_URL` 必须是后端**公网可达地址**（`http://<IP或域名>:8000`），
   写 `localhost` 会导致浏览器端请求失败。

## 5. 生产环境注意事项

| 事项 | 说明 |
|---|---|
| 会话持久化 | `_sessions` 是内存字典，重启即丢；多副本部署需改为 Redis |
| 并发 | 后端 Uvicorn 可用 `--workers N`；但多进程下内存会话不共享，建议先单 worker 或改 Redis |
| 密钥安全 | 只通过 `.env` / 平台环境变量注入，禁止硬编码或提交仓库 |
| 中文字体 | 容器/服务器缺字体时图表中文变方块，安装 `fonts-wqy-zenhei` |
| 文件存储 | `charts/ reports/ uploads/ data/` 为本地目录；多副本请改对象存储或共享卷 |
| 日志 | 后端日志由 Uvicorn 输出；业务轨迹可查 `GET /logs/{session_id}` |
| 备份 | 定期备份 `data/agent.db` 与 `reports/` |
| 限流 | LLM 上游有 QPS 限制，`eval.py` 的 `--workers` 不要调得过高 |

## 6. 部署后自检清单

- [ ] `curl http://<host>:8000/health` 返回 `{"status":"ok","tools":11}`
- [ ] `curl http://<host>:8000/tools` 返回工具清单
- [ ] 浏览器打开前端，页头显示「后端在线」
- [ ] 上传 CSV → 提问 → 能看到回答、图表与执行轨迹
- [ ] 打开 SSE 开关后，推理过程逐行出现（而非一次性出现）
