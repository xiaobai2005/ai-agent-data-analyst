# 自定义工具集 · 使用说明（Markdown）

> 适用对象：数据分析 Agent（智能数据分析助手）的全部自定义工具
> 配套 Schema：`tools_schema.json`（JSON Schema Draft-07）
> 源码位置：`tools/*.py`（LangChain `@tool` 注册）、`agent.py`（工具注册与编排）

---

## 0. 总览

Agent 共注册 **11 个工具**，覆盖「数据画像 → 预览 → 查询 → 统计 → 可视化 → 计算 → 报告」完整分析链路。所有工具统一约定：

- **入参**：具名 JSON 字段（与函数签名、JSON Schema 一致）。
- **返回值**：**字符串**（Markdown / 纯文本 / 相对路径）。返回字符串是因为工具结果要塞回对话消息发给大模型，DataFrame 等对象塞入会报错（实际踩过的 400 坑）。
- **安全**：文件类工具统一经 `guard.safe_path` 校验，禁止绝对路径与 `..` 父目录穿越。

| 工具 | 用途 | 典型输入 | 何时用 |
|------|------|----------|--------|
| `profile_csv` | 数据画像（编码/类型/缺失/基数） | `csv_path` | 首次了解文件结构时 |
| `read_csv` | 预览前 N 行 | `file_path`, `nrows` | 只想看几行样例时 |
| `sql_query` | 只读 SQL 查询 | `csv_path`, `sql` | 需要筛选/排序/多条件/复杂聚合时 |
| `stats_summary` | 数值列描述统计 | `csv_path` | 求 mean/min/max/std 时 |
| `stats_value_counts` | 某列取值计数 | `csv_path`, `column` | 数某列各取值出现次数时 |
| `stats_group_agg` | 分组求和与均值 | `csv_path`, `group_by`, `column` | 按地区/产品分组统计时 |
| `stats_mom` | 环比增长率 % | `csv_path`, `date_col`, `value_col` | 涉及逐期对比时 |
| `stats_yoy` | 同比增长率 % | `csv_path`, `date_col`, `value_col` | 涉及年度对比时 |
| `make_chart` | 图表生成（5 类） | `csv_path`, `chart_type`, `x`, `y` | 需要可视化时 |
| `calculator` | 安全算术计算 | `expression` | 纯算术表达式时 |
| `report_tool` | 生成 Markdown 报告 | `markdown_body`, `title` | 用户要求「报告」时 |

## 1. 调用流程（Agent 编排）

```
用户问题 + 当前 csv 路径 + 自动数据画像
        │
        ▼
System Prompt（角色 / 工具清单 / 图表规则）
        │
        ▼
LLM 思考(Thought) → 选择工具与参数 → 调用
        │
        ▼
工具执行（经安全护栏）→ Observation 回填
        │
        ▼
未完成则循环；完成则结构化回答（含图表/报告）
```

要点：
- `profile_csv` 在文件首次或发生变化时由系统自动调用，并把「数据画像」注入 System Prompt，后续分析优先参考其中的列名/类型/缺失值。
- `make_chart` 调用后，**必须**在最终回复的对应段落用 Markdown 图片语法引用返回路径，否则图表无法显示：
  ```markdown
  ![各地区销量柱状图](charts/chart_bar_region_xxxxxxxx.png)
  ```
  路径即 `make_chart` 返回里 `图表已保存:` 后的相对路径，不带域名。

## 2. 逐工具用法与示例

### 2.1 profile_csv
```json
{ "csv_path": "demo.csv" }
```
返回数据画像文本（行数、列类型、缺失值、唯一值基数、统计概览）。**建议每轮分析前先跑它了解数据。**

### 2.2 read_csv
```json
{ "file_path": "demo.csv", "nrows": 5 }
```
`nrows` 默认 5。文件不存在返回 `错误：文件不存在`；空文件返回 `错误：文件是空的`。

### 2.3 sql_query（只读）
```json
{ "csv_path": "demo.csv",
  "sql": "SELECT region, SUM(quantity) FROM demo GROUP BY region" }
```
- CSV 首次会自动导入 SQLite，表名 = 文件名去后缀（如 `demo`）。
- **仅放行以 `SELECT` 开头的查询**，结果最多 20 行。
- 危险关键字（DROP/DELETE/UPDATE/INSERT/ALTER/CREATE/TRUNCATE/ATTACH/PRAGMA/VACUUM）被硬拦截，并以只读连接执行（双保险）。
- 触发拦截示例：`DROP TABLE demo` → 返回 `错误：检测到危险 SQL 操作...已被安全护栏拦截。`

### 2.4 stats_summary
```json
{ "csv_path": "demo.csv" }
```
对所有数值列输出 `count/mean/std/min/25%/50%/75%/max`（保留 4 位小数）。

### 2.5 stats_value_counts
```json
{ "csv_path": "demo.csv", "column": "product" }
```
列名不存在时返回：`错误：列不存在，可用列 [...]`，便于模型自我纠正。

### 2.6 stats_group_agg
```json
{ "csv_path": "demo.csv", "group_by": "region", "column": "quantity" }
```
按 `group_by` 分组，对 `column` 计算 `sum` 与 `mean`。分组列与数值列均须存在。

### 2.7 stats_mom（环比）
```json
{ "csv_path": "demo.csv", "date_col": "date", "value_col": "quantity" }
```
按日期分组求和，再算相邻期 `pct_change`。返回「日期 / 数值 / 环比%」。

### 2.8 stats_yoy（同比）
```json
{ "csv_path": "demo.csv", "date_col": "date", "value_col": "quantity" }
```
解析日期→按年汇总→算年度变化率。返回「年份 / 数值 / 同比%」。

### 2.9 make_chart
```json
{ "csv_path": "demo.csv", "chart_type": "bar", "x": "region", "y": "quantity" }
```
- `chart_type` 白名单：`line` / `bar` / `scatter` / `hist` / `pie`。
- `hist`、`pie` **不需要** `y`：`hist` 看分布，`pie` 不传 `y` 时按 `x` 计数。
- 返回 `图表已保存: charts/chart_<type>_<x>_<uuid前8位>.png`，文件名 UUID 唯一，避免覆盖导致前端漏图。

### 2.10 calculator
```json
{ "expression": "(3+5)*12" }
```
- 仅允许数字与 `+ - * / ( ) . %`，**禁用任何字母**（防 `__import__('os')` 注入）。
- 清空内置环境 `{"__builtins__": {}}`，即使字符检查被绕过也拿不到函数。
- 限制 `**` 最多出现 1 次，防嵌套乘方卡死；长度上限 100 字符。
- `(3+5)*12` → `96`。

### 2.11 report_tool
```json
{ "markdown_body": "## 关键发现\n- 上海销量最高（83 件）\n![图](charts/chart_bar_region_xxx.png)",
  "title": "地区销量分析" }
```
保存到 `reports/report_<时间戳>.md`，返回保存路径。

## 3. 设计要点与踩坑

1. **「选工具」优于「填参数」**：早期把统计做成「一个函数 + operation 参数」，模型填参数易错；后拆成 `stats_summary / stats_value_counts / stats_group_agg / stats_mom / stats_yoy` 五个独立工具，像把「模式+数值」两个键做成多个标了名字的专用键，调用准确率明显提升。
2. **列名自我纠正**：`stats_*` 系列在列名不存在时返回「可用列」提示，模型据此重试，避免直接失败。
3. **图表路径竞态**：早期用「目录 diff」判断新图，并发时漏图；改为从工具消息里解析 `图表已保存:` 前缀，并用 UUID 唯一命名。
4. **返回必须是字符串**：工具结果塞回对话消息，非字符串对象会导致大模型接口 400。
5. **安全三道护栏**：路径校验、SQL 危险字拦截 + 只读连接、计算器字符白名单 + 空内置环境。删除类高风险操作额外触发 HITL（人工确认）。

## 4. 使用约定速查

- 多步任务要自主拆解：如「对比两月趋势找异常」→ 先 `stats_group_agg`，再 `make_chart`，最后给结论。
- 最终回复结构化：关键发现 + 具体数字 + 简短建议。
- 用真实数据作答，**禁止编造数字**；所有数值必须来自工具返回。
- 多轮追问（如「换成饼图」「加上环比」）参考上一轮对话上下文。
